# openspec/ — Spec-Driven Development workspace

- `config.yaml` — project SDD config: context, strict TDD, testing capabilities, per-phase rules.
- `specs/` — source of truth (main specs), merged from archived changes.
- `changes/` — active changes; each change folder holds state.yaml, proposal, specs deltas, design, tasks, verify-report.
- `changes/archive/` — completed changes (audit trail, never modified).
